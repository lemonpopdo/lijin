# 既有问题记录

本文档记录阶段 1 已知问题，避免后续阶段误判为新引入的缺陷。每条说明「现象 / 原因 / 是否修复」。

## 1. `bookItem/edit.vue` 的 `wd-form` 缺 `:model`

- 现象：`wd-form` 上缺少 `:model` 绑定
- 原因：`@wot-ui/ui@2.3.1` 中该 prop 为 `makeRequiredProp`，上游既有缺陷
- 是否修复：已修复（已添加 `:model="currentItem"`）

## 2. vendored 图表组件 lint 豁免

- 现象：`src/components/qiun-data-charts/`、`src/components/u-charts/` 等第三方图表组件存在大量 lint 问题
- 原因：这些组件是 vendored 第三方代码，含依赖特定写法的 canvas 绘制代码
- 是否修复：已加 `eslint.config.js` ignores，不做格式化

## 3. 误打包的 PocketBase 文件已删除

- 现象：根目录曾存在 `types.d.ts`、`CHANGELOG.md`、`LICENSE.md`
- 原因：PocketBase 发行包文件被误随二进制一起放入项目
- 是否修复：已删除。`types.d.ts` 含全局声明（`declare const Record`、`declare class Collection` 等），eslint 会扫到且可能导致类型冲突；`CHANGELOG.md` 是 PocketBase v0.39.9 日志；`LICENSE.md` 是 PocketBase 的 MIT 许可证，与本项目 `LICENSE`（GPL-3.0）并存会造成混淆

## 4. `/oss/assets/*` 远程静态资源 404

- 现象：`src/pages/mine/index.vue:92`、`src/pages/subscription/index.vue:19,26,34,41`、`src/pages/subscription/plan.vue:144,158` 中用 `serviceUrl` 拼接的背景图 404
- 原因：生产环境 `VITE_SERVICE_URL` 为空导致取不到
- 是否修复：暂不修复，仅影响装饰性背景，不影响功能

## 5. `src/pages/contact/index.vue` 中硬编码图片地址

- 现象：硬编码的 `https://liji.poetic.ltd/...` 图片地址（原作者服务器）
- 原因：上游遗留
- 是否修复：暂不修复

## 6. 头像上传未适配 PocketBase 文件字段

- 现象：当前 `apiUserAvatarPut` 为 stub
- 原因：PocketBase 文件字段适配未完成
- 是否修复：暂不修复，阶段 2 处理

## 7. `VipLevelTag.vue` 与 `mine/index.vue`、`subscription/index.vue` 对 `accountType` 2/9 的映射相反

- 现象：不同文件中 `accountType` 2 和 9 的 VIP 判断逻辑相反
- 原因：上游既有不一致
- 是否修复：**不要去「修正」**，当前统一使用 2

## 8. 礼簿聚合字段缺失

- 现象：`books` 的 `count`、`attendanceTotal`、`moneyTotal` 三个字段读取时为 `undefined`
- 原因：原本由 .NET 后端计算后返回，PocketBase 不提供该能力。`adapter.ts` 的 `transientFields` 已正确将其从写入 payload 中剔除，但读取时没有地方计算这三个值
- 是否修复：暂不修复，礼簿不是本项目重点

## 9. 回收站页面为空壳

- 现象：`src/pages/recycle/index.vue` 内容为 `<template><div /></template>`
- 原因：上游即为空壳
- 是否修复：无需实现

## 10. `package.json` 中 `version` 与代码包目录名不一致

- 现象：`package.json` 中 `version` 为 5.0.0，代码包目录名为 6.1.1
- 原因：上游版本号未更新
